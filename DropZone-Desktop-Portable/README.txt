========================================================================
DROPZONE Desktop (Cross-Platform Framework-Dependent Release)
Move Files. Not Your Privacy.
========================================================================

This package is a framework-dependent deployment for Windows, Linux, and macOS.
Requires .NET 11 Runtime installed on the host.

HOW TO RUN:
- Windows: Run "Run-Portable.bat" or execute: dotnet DropZone.UI.dll
- Linux: dotnet DropZone.UI.dll (ensure libdropzone_engine.so is in LD_LIBRARY_PATH)
- macOS: dotnet DropZone.UI.dll (ensure libdropzone_engine.dylib is available)
========================================================================
