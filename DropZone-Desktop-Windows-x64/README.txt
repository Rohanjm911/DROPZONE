========================================================================
DROPZONE Desktop (Windows x64 Standalone Release)
Move Files. Not Your Privacy.
========================================================================

This package is a standalone, self-contained Windows application.
It contains the full embedded .NET runtime and native Rust networking engine.
No external runtime installation is required.

HOW TO RUN:
1. Double-click "DropZone.exe" or "Run-DropZone.bat".
2. Allow Windows Firewall access on local networks for mDNS discovery.
3. Start sharing files securely!

COMPONENTS:
- DropZone.exe: Standalone application executable
- dropzone_engine.dll: Rust Tokio binary transport engine (DZP1)
- libSkiaSharp.dll / libHarfBuzzSharp.dll: GPU accelerated text and graphics
- e_sqlite3.dll: Embedded SQLite database engine (WAL mode)
- av_libglesv2.dll: Direct3D / OpenGL rendering support
